# Lista de compras

Puedo anotar en cualquier momento lo que necesito comprar.

## Datos de cada ítem
| Campo | Notas |
|---|---|
| Nombre | **obligatorio** |
| Cantidad | |
| Precio estimado | opcional |
| Dónde comprarlo | opcional |
| Prioridad | |
| Categoría | |

## Comportamiento
- Marcar como **comprado** → la app ofrece registrarlo como gasto ([[Movimientos]]) en una cuenta, con el **precio real**.
- Muestra el **total estimado** de la lista, sumando solo los ítems que tienen precio.
